# Higher-Lower Game👆👇

A simple Python game where players compare two people, brands, or entities and guess which one is more popular.

The game presents two options and challenges the player to choose the one with the higher popularity score. The game continues until an incorrect guess is made.

## Features
- Compare two different entities
- Track the player's score
- Simple command-line interface
- Built using Python

## Technologies Used
- Python

## How to Play
1. Run the program.
2. Compare the two displayed options.
3. Guess which option is more popular.
4. Continue playing and try to achieve the highest score possible.
